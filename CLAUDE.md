This repository uses repo-local memory. Before making changes, read the project memory documents and the existing handoff rules.

## Required startup steps

1. Read `AGENTS.md`.
2. Read `HANDOFF.md`.
3. Read `README.md`.
4. Read `public-template-policy.md`.
5. Read `docs/PROJECT_MEMORY.md`.
6. Read `docs/RUNBOOK.md`.
7. Read `docs/OPERATIONS_LOG.md` when recent work may matter.
8. For website writing or prompt-box changes, read `site-plan/web-writing-sop.md`.
9. Treat repo documents as the source of truth over Nowledge Memory, Working Memory, or raw Threads.
10. Do not overwrite unrelated user changes.

## Safety rules

- This is a public teaching-site and flow-pack repo. Keep examples fake, generic, reusable, and safe for public sharing.
- Do not commit official Dingxi crest files, mascot reference files, internal banner images, OAuth tokens, client secrets, API keys, cookies, sessions, real Gmail data, real Calendar IDs, public-document case details, personal data, account identifiers, usage-quota details, browser profiles, or logged-in screenshots.
- The internal UNC brand-source path may be documented as a pointer, but actual official brand files must not be included in this public repo.
- Maintain the teaching model: 看成果 -> 學方法 -> 拿流程包.
- Keep the static-site architecture unless there is a clear need to add a build system.

## Memory update policy

Update memory docs after significant changes to public-sharing policy, website teaching sequence, flow-pack inventory, archived/current distinctions, deployment/public-access procedure, web-writing SOP, safety checks, or brand-source handling.

Security, privacy, account, organization, permission, and cross-project rules require explicit user confirmation before being written as memory.

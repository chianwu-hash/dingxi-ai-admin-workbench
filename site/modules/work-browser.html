第 5 單元

建立 AI 工作瀏覽器

安裝必要工具、建立一個 AI 可以協助操作的工作瀏覽器，登入過的網站之後可以在同一個工作瀏覽器裡重用。

設定一次，之後說一句話就好

這個單元只需要做一次設定：安裝瀏覽器自動化工具、建立一個和日常 Chrome 分開的工作瀏覽器。

設定完成後，之後每次只要對 Codex 說「開啟AI工作瀏覽器」，AI 就會先開啟 ChatGPT；需要其他網站時，也可以在同一個工作瀏覽器登入使用。

複製給自己的 AI 助手

這段提示詞會分三步驟進行。AI 完成安裝後會停下來等你登入，你登入完成後告訴 AI「我登入好了」，它再把快捷語句寫進本機等級的 Codex 規則。

提示詞

請依序完成三件事：安裝必要工具、建立 AI 工作瀏覽器，以及設定重開瀏覽器的快捷語句。

【第一部分：安裝必要工具】

請確認這台 Windows 電腦是否已備妥必要環境，並安裝或更新這個 repo：

https://github.com/chianwu-hash/browser-automation-workflow
安裝至 D:\projects\browser-automation-workflow

這個 repo 的 npm install 會自動帶入 cbs-workflows 與 cdp-tools，不需要另外 clone 或安裝那兩個 repo。

請依序：
- 確認 Git、Node.js、npm 是否可用
- 資料夾不存在時 clone browser-automation-workflow；已存在時確認 remote 正確後更新到最新版本
- 進入 D:\projects\browser-automation-workflow 執行 npm install
- 執行 npm run skills:install；如果已安裝但需要更新，改用 npm run skills:install:force
- 執行 npm run check
- 確認 browser:init、browser:status、browser:smoke 這幾個 npm script 可用
- 確認 browser-automation-workflow 可以找到 ChatGPT 生圖相關指令

【第二部分：建立 AI 工作瀏覽器】

安裝完成後，繼續：
- 檢查是否已有 AI 工作瀏覽器 profile（預設名稱 chatgpt，放在 D:\chrome-cdp-profiles）
- 沒有的話，建立這個 profile
- 不要使用我的日常 Chrome profile
- 在 D:\projects\browser-automation-workflow 執行 npm run browser:init -- -- --app chatgpt --browser chrome --port 9222 --yes
- 用這個工作瀏覽器開啟 ChatGPT 網頁後，停下來等我手動登入
- 我說「我登入好了」之後，執行 npm run browser:status -- --ports 9222 與 npm run browser:smoke，確認登入狀態可以保留，並回報之後重用的指令
- 如果我之後要使用 ChatGPT 以外的網站，請在同一個工作瀏覽器開啟該網站，停下來等我手動登入；登入狀態會由工作瀏覽器保存

【第三部分：設定重開瀏覽器快捷語句】

完成以上步驟後，請把以下規則加入本機等級的 Codex 指令檔 ~/.codex/AGENTS.md
（Windows 通常在使用者資料夾下的 .codex\AGENTS.md；檔案不存在時請建立，已存在時附加到檔案結尾）。
不要把這段本機規則寫進目前專案的公開 AGENTS.md；如果無法判斷本機等級 AGENTS.md 的位置，請先停下來問我。

## AI 工作瀏覽器

當使用者說「開啟AI工作瀏覽器」時：

1. 進入 D:\projects\browser-automation-workflow
2. 執行 npm run browser:init -- -- --app chatgpt --browser chrome --port 9222 --yes
3. 執行 npm run browser:status -- --ports 9222 確認工作瀏覽器已開啟並連線
4. 如果使用者沒有指定網站，預設開啟 ChatGPT
5. 如果使用者指定 ChatGPT 以外的網站，請在同一個工作瀏覽器開啟該網站
6. 如果是第一次登入某個網站，停下來等使用者手動登入
7. 使用者說「我登入好了」後，確認該網站可以在工作瀏覽器中繼續使用
8. 如果登入狀態還在：直接回報可以開始使用；如果已登出：開啟對應網站後停下來等使用者重新登入

與使用者溝通時，不要提到 CDP、port、Playwright、session file、browser profile
等技術詞，改用「工作瀏覽器」、「已儲存的登入狀態」等白話說明。

寫入完成後，請告訴使用者：
「設定完成。以後只要對我說『開啟AI工作瀏覽器』，
我就會幫你開啟工作瀏覽器。預設會先開 ChatGPT；如果你指定其他網站，也可以在同一個工作瀏覽器登入使用，不需要再複製提示詞。」

【安全規則】

- 不要讀取、輸出或提交我的 cookie、session、密碼、驗證碼、登入畫面或 browser profile 內容
- 工作瀏覽器可以保存登入狀態，但不要把登入狀態、cookie 或 session 當成可讀取或可分享的資料
- browser profile 不要放進任何 Git repo 或專案資料夾
- 不要截圖登入畫面
- 不要用任何真實學生、家長或教職員資料測試
- 需要執行送出、刪除、寄信、公告、匯入或修改正式資料的動作前，請先停下來問我
- 看到陌生網站或不確定的登入頁，請先停下來讓我確認
- 如果你沒有本機操作或安裝權限，請用我看得懂的步驟帶我完成，不要只丟文件連結給我

完成後請用簡短清單回報：
- 已安裝或更新的 repo 與本機路徑；並說明 cbs-workflows 與 cdp-tools 是由 npm install 自動帶入
- 哪些安裝檢查通過
- AI 工作瀏覽器是否建立並可重用
- 本機等級 AGENTS.md 更新位置
- 之後說哪句話可以重開工作瀏覽器
設定後

說一句話重開

設定完成後，之後只要對 Codex 說「開啟AI工作瀏覽器」，AI 就會開好同一個工作瀏覽器，預設先進 ChatGPT。

其他網站

同一個工作瀏覽器登入

如果之後要用其他網頁工具，可以在同一個工作瀏覽器登入。登入狀態會保存，但密碼和驗證碼仍然要自己處理。

登入失效時

說同一句話就好

如果工作瀏覽器被關掉或登入失效，說「開啟AI工作瀏覽器」，AI 會重新開啟並在需要時請你重新登入。

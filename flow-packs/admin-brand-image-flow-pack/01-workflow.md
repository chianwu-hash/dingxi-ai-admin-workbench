# 品牌行政圖像製作流程

```text
寫出可見文字
-> 決定輸出類型
-> 保留校徽/頁碼安全區
-> 生成圖像
-> 人工檢查
-> 固定 overlay
-> 匯出
```

輸出類型：

- 行政簡報
- LINE 小卡
- 公告圖卡
- 海報

## 會議通知小卡最小流程

```text
確認日期/時間/地點/主題
-> 整理成圖片上可見文字
-> 使用 AI 工作瀏覽器進入 ChatGPT
-> 生成 16:9 橫式草稿
-> 檢查文字、假 logo、個資與安全區
-> 需要正式校徽時用固定 overlay 後製
```

會議通知小卡適合作為第一個練習，因為欄位少、格式固定、容易檢查。

# 會議通知小卡流程包

## 這是什麼？

這個流程包協助行政同仁把既有會議資料整理成一張可檢查、可修正的會議通知小卡。網站第 6 單元把它當作 AI 工作瀏覽器的第一個小作品。

## 核心原則

- 可以先請 AI 從現有會議資料、Email、LINE 訊息或行事曆內容整理欄位。
- 小卡文字要大、少、手機可讀；日期、時間、地點發布前一定要自己確認。
- LINE 群組通常適合直式小卡；Email、簡報或網頁嵌入通常適合橫式小卡。
- 生成後檢查文字可讀性、日期、地點、個資、QR code、會議連結與不必要的裝飾元素。

## 分享方式

公開 repo 放 prompt 與 checklist；真實會議資訊發布前由承辦人自行確認。

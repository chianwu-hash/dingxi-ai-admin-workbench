# 會議通知小卡製作流程

```text
收集現有會議資料
-> 請 AI 整理小卡欄位
-> 人工確認可見文字
-> 決定發布管道
-> 生成圖片草稿
-> 人工檢查
-> 需要時修正尺寸或文字
-> 匯出
```

輸出類型：

- LINE 小卡
- Email 圖卡
- 簡報或網頁嵌入圖

## 會議通知小卡最小流程

```text
貼上現有會議資料，或手動提供日期/時間/地點/主題
-> 整理成圖片上可見文字
-> 確認發布管道，未定時先用 16:9 橫式
-> 使用 AI 工作瀏覽器進入 ChatGPT
-> 生成 16:9 橫式草稿
-> 檢查文字、日期、地點、個資與不必要的標誌或印章
```

會議通知小卡適合作為第一個練習，因為欄位少、格式固定、容易檢查。

尺寸可依發布管道調整：LINE 群組通常適合直式小卡；Email、簡報或網頁嵌入通常適合橫式小卡。第一次練習建議先用 16:9 橫式跑完流程，確認內容正確後，再請 AI 改成 LINE 直式版本。

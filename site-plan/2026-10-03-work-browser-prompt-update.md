# AI 工作瀏覽器安裝提示更新

## 範圍

更新第 5 單元安裝提示，對齊 browser-automation-workflow 的選用分身功能。這是既有提示的相容性修訂，不是新增或重新完成整個單元；未啟動單元收尾的 Claude 審查。

## 設計決定

- 首次設定預設一個工作瀏覽器；使用者明確要求時才啟用分身。
- 安裝後告知「我想要使用 AI 工作瀏覽器分身」的入口，啟用時再引導網站登入。
- Chrome 帳號與同步選用，不會同步網站登入狀態。
- 安裝提示引用最新技能與參考文件，保留本機共用啟動器優先與占用分配，移除固定埠號及舊 browser:init 設定配方。
- 更新前保留 repo 修改與原瀏覽器設定；快捷規則只引用技能，不另抄完整技術流程。

## 主旨清單與刪除檢查

使用者說明與可單獨複製的 AI 指令分別檢查。AI 指令需自足，不能仰賴提示之外的頁面文字。

| 區塊 | 唯一主旨 |
| --- | --- |
| 頁首導言 | 工作瀏覽器用途與登入狀態重用 |
| 準備段落 | 備妥網站帳號與學校安裝權限 |
| 安裝指令 | 相容環境、安裝技能並保留既有修改 |
| 開啟與驗證指令 | 依技能分配、登入與原生下載驗證 |
| 快捷語句指令 | 更新本機規則且委由技能維護技術細節 |
| 安全與回報指令 | 資料界線、授權、安裝權限替代方案與誠實回報 |
| 設定後卡片 | 下次開啟的語句與預設網站 |
| 其他網站卡片 | 其他網站登入與密碼／驗證碼由自己處理 |
| 選用功能卡片第一段 | 多對話分身的啟用語句與各分身網站登入 |
| 選用功能卡片第二段 | Chrome 同步的用途與非必要性 |

刪除原先重複說明設定及快捷語句的導言，將「登入失效時說同一句話」卡片改為分身入口。各保留區塊分別承擔準備、操作或登入知識，不再重述同一個快捷語句情境。

教學效能站同步更新安裝提示：頁首交代教學用途，三張卡片分別負責沿用設定、取得工具、老師登入與試用；複製段落交代如何交給 AI；分身段落交代選用入口及 Chrome 同步；唯一提醒框負責教材授權與學生資料界線。

## 驗證方式

以 Git 暫存區版本執行網站連結、提示複製結構、公開檔案安全及 JSON 檢查，再以已登記的 AI 工作瀏覽器檢查兩站桌面／手機寬度和複製按鈕。其他既有未提交修改不納入本次發布。

驗證結果：

- 行政站 22 個 HTML、9 個流程包 JSON，以及教學站 19 個 HTML 的本機連結與公開檔案安全檢查通過；未發現本機 Markdown 連結或官方品牌來源檔。
- 兩站目標頁均保留一個複製按鈕，載入原有複製程式，包含新版管理入口與環境需求，沒有舊 browser:init 安裝配方。
- 已登記的工作瀏覽器實測兩站 1440px 與 390px 寬度：無水平溢出，圖片正常載入。
- 點擊原有按鈕後，複製處理器送出的全文與提示內容一致，按鈕顯示「已複製」。測試攔截 clipboard.writeText 以核對內容，未覆寫或讀取使用者系統剪貼簿；未測試作業系統剪貼簿權限。
- Git 暫存區差異檢查通過。沒有重新安裝工具、啟用新分身、登入網站或測試產圖；本次驗證只針對教材頁面。
